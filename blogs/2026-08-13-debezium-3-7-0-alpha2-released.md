We’re pleased to announce the release of Debezium 3.7.0.Alpha2 , the second preview release in the 3.7 series, packed with new features and important changes across the platform. This release introduces an incubating TiDB connector, adds retry and dead letter queue support for the JDBC sink, and improves Debezium Server with a proper readiness probe. On the Oracle side, the OpenLogReplicator client is now non-blocking and continuous mining for Oracle 12 has been removed.

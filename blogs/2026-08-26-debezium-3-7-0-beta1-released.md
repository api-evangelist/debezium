As summer continues, we’re excited to announce the release of Debezium 3.7.0.Beta1 , bringing a broad set of improvements across connectors, Debezium Server, and the Platform UI. Among the highlights, incremental snapshots now work on PostgreSQL read-only replicas, and Debezium Server gains a new Databricks ZeroBus Ingest sink for direct change event delivery to Unity Catalog-managed Delta tables. This release also includes performance and snapshot optimizations, new connector capabilities, and numerous bug fixes across the board.
